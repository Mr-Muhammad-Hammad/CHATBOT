# AI Chatbot (Flask + Ollama)

A simple web chatbot that runs fully on your own computer. The web page is built with Flask, HTML, CSS and JavaScript, and the replies come from a local AI model served by [Ollama](https://ollama.com). No API key and no internet connection are needed after the model is downloaded.

## Features

- Chat interface in the browser
- Replies generated by a local model (`llama3.2:1b` by default)
- Model and server address configurable through a `.env` file
- Error message shown in the chat if Ollama cannot be reached

## How it works

1. You type a message in the browser.
2. `chat.js` sends it to the Flask route `/chat` as JSON.
3. `app.py` passes it to the Ollama server running on your PC.
4. Ollama returns the model's reply, and Flask sends it back as JSON under the key `response`.
5. `chat.js` shows it in the chat window.

## Requirements

- Python 3 installed
- [Ollama](https://ollama.com/download) installed and running
- About 1.3 GB of free disk space for the default model

## Installation

### 1. Download the project

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

Or download the ZIP from GitHub and extract it.

### 2. Download the AI model

```bash
ollama pull llama3.2:1b
ollama list
```

`ollama list` should show `llama3.2:1b`.

### 3. Create and activate a virtual environment

**Windows (PowerShell):**
```powershell
python -m venv venv
venv\Scripts\activate
```

If PowerShell blocks the activation script, run this once in the same window and activate again:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install the packages

```bash
pip install -r requirements.txt
```

### 5. (Optional) Change the settings

Copy `.env.example` to `.env` and edit it:

```
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2:1b
```

If there is no `.env` file, the app uses these same values by default.

### 6. Run the app

```bash
python app.py
```

Open the address printed in the terminal, usually `http://127.0.0.1:5000`.

## Using a different model

1. Download it, for example: `ollama pull <model-name>`
2. Put the exact name shown by `ollama list` in `OLLAMA_MODEL` in your `.env` file.
3. Restart the Flask app. The `.env` file is only read at startup.

## Troubleshooting

| Problem | What to check |
|---|---|
| Chat shows `Error: ...` | Ollama is not running, or the address in `.env` is wrong. Start the Ollama app and check `OLLAMA_BASE_URL`. |
| Error says the model was not found | The model name does not match. Run `ollama list` and copy the exact name into `.env`. |
| Bot messages show `undefined` | `chat.js` must read `data.response`, the same key `app.py` returns. Hard refresh the browser with `Ctrl+Shift+R`. |
| Page looks old after editing files | Hard refresh with `Ctrl+Shift+R` to clear the cached CSS and JavaScript. |
| First reply is slow | The model loads into memory on first use. Later replies are faster. |
| `ModuleNotFoundError` | The virtual environment is not active, or `pip install -r requirements.txt` was not run. |
| `ollama` command opens a menu of tools | Running `ollama` with no extra word opens an interactive menu. Use specific commands like `ollama pull` and `ollama list` instead. |

## Limitations

- **No conversation memory.** Each message is sent to the model on its own, so it does not remember earlier messages.
- **Small model.** `llama3.2:1b` is lightweight and can give wrong or made-up answers. Do not trust links, facts or numbers it gives without checking.
- **No internet access.** The model cannot search the web.
- **Development server.** `debug=True` in `app.py` is for local use only. Do not use it for public hosting.
